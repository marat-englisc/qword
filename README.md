# qword

Простое приложение для изучения значений английских слов. Колоды встроены в приложение;
пользователь может просматривать значения и заниматься, но не создавать или редактировать контент.
Регистрации, сервера и удалённой базы нет.

## Запуск

```sh
npm install
npm start
```

Откройте проект в Expo Go на Android или iOS. Модули используются в версиях для Expo SDK 57.
Для просмотра в браузере: `npm run web`, адрес `http://localhost:8090`.
Эта команда собирает приложение и запускает локальное превью. После изменения кода запустите её снова.
Так обходим ошибку Metro `Worker chunk not found` для SQLite в web dev-режиме текущего SDK.
SQLite на web использует экспериментальную поддержку Expo; заголовки настроены
в плагине Expo Router в `app.json`. Для разработки на телефоне используйте обычный `npm start`.

## Зависимости

Для повторяемой установки используйте `npm ci`. Новые пакеты устанавливайте через
`npx expo install <пакет>`; совместимость с Expo SDK 57 проверяется командой
`npx expo install --check`, исправляется — `npx expo install --fix`.

NativeWind 4.2.7 требует Tailwind CSS 3; проект использует ветку `~3.4.19`.
В `package.json` закреплены исправленные вложенные зависимости:
`postcss-selector-parser@7.1.6` для Tailwind и `uuid@11.1.1` для Xcode.
Скрипты установки esbuild и unrs-resolver разрешены только для проверенных версий
через `allowScripts`. После обновления этих пакетов проверьте
`npm install-scripts ls` и разрешайте скрипты нужных версий отдельно.

`npm audit fix --force` может откатить Expo и установить несовместимые версии
React Native или Tailwind. Оставшиеся предупреждения нужно разбирать отдельно:
для braces и node-forge пока нет исправленных релизов, а исправленный
decode-uri-component 0.5 использует ESM и несовместим с CommonJS-вызовом
в query-string 7, который используется Expo Router 57.

## Где добавлять контент

Контент находится в `local.db`. Для редактирования можно использовать `npx drizzle-kit studio`.
Путь к базе для Drizzle Kit задаётся в `.env` через `DB_FILE_NAME`.

- `deck` — колоды.
- `card` — слово (`title`), транскрипция (`transcription`) и ссылка на колоду.
- `card_meaning` — отдельное значение слова: `hint`, английское определение
  (`meaning`), русский перевод определения (`meaning_translation`).
- `card_example` — английский пример и его перевод, привязанные к `card_meaning_id`.

Например, у одной записи `card` со словом `run` могут быть два значения:
«бежать» и «запускать программу». У них разные ID, подсказки, примеры и прогресс FSRS.
Лицевая сторона показывает слово, транскрипцию, озвучку и подсказку выбранного значения.
Обратная — слово, транскрипцию, определение, его перевод и примеры этого значения.

При первом запуске `local.db` копируется в SQLite-базу `qword-meanings.db` на устройстве.
Следующие запуски используют эту копию, сохраняя прогресс пользователя.
Старая база `qword.db` с таблицами `decks` и `words` остаётся на устройстве;
новая схема со значениями использует отдельный файл.
При запуске приложение проверяет, изменился ли исходный файл. Если изменился,
добавляет новые записи и обновляет существующие в таблицах контента.
Прогресс FSRS и добавленные пользователем колоды сохраняются. Не меняйте ID значений,
для которых хотите сохранить прогресс. Удаления из исходной базы автоматически не переносятся.
После редактирования `local.db` сделайте полный Reload в Expo Go.
Если Metro не подхватил изменение файла, перезапустите его через `npm start -- --clear`.
Для web заново запустите `npm run web`, затем обновите страницу.

## Как устроено

- `src/app/` — три экрана и корневой layout Expo Router.
- `src/components/WordCard.tsx` — передняя и задняя стороны карточки, озвучка.
- `src/db/schemas/` — таблицы Drizzle: колоды, слова, значения, примеры и прогресс.
- `src/config/connection.ts` — асинхронное подключение к локальному Expo SQLite.
- `src/db/importContent.ts` — добавление и обновление контента из исходной базы.
- `src/db/repositories/` — чтение контента, сохранение прогресса и журнал ответов.
- `src/store.ts` — Zustand: список колод и текущая тренировка.
- `src/lib/scheduler.ts` — TS-FSRS, четыре оценки и форматирование интервалов.
- `src/lib/study.ts` — выбор значений для повторения и добавление новых.
- `src/theme.ts` — тема React Native Paper. NativeWind используется для расположения элементов.

SQLite-файл `qword-meanings.db` хранится на устройстве и сохраняется между запусками.
Обучение берёт значения только из добавленных пользователем колод. Сначала идут наступившие
короткие повторения, затем обычные повторения по риску забывания. Новые значения чередуются
с повторениями, не более 10 в день для всех колод; день начинается в 04:00.
После каждой оценки очередь пересчитывается. Если короткий срок FSRS наступает,
значение снова появляется в открытой практике. Открытую карточку таймер не заменяет.
Ответ сохраняется сразу при выборе оценки по `meaning.id`. Просмотр значения в колоде
не меняет прогресс. Полоса «Знакомы» считает значения, на которые уже был дан ответ.

Drizzle использует `sqlite-proxy` как небольшой адаптер к async API Expo SQLite.
Несмотря на название драйвера, все запросы выполняются локально, без сети.

Озвучка — системный синтез речи через Expo Speech, язык `en-GB`. Аудиофайлов и внешнего API нет.
Для работы без интернета установите английский голос на устройстве. На iPhone отключите
беззвучный режим. Качество голоса зависит от устройства.

Исходный `App.tsx` сохранён; приложение запускается через `index.ts` → Expo Router.
Если меняете структуру таблиц, обновите Drizzle-схему и исходную `local.db`.
Для уже установленных копий понадобится отдельная миграция в `initializeDatabase`.
